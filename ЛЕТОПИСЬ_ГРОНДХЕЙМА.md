## 1. Фрактал из одной единицы

Грондхейм — не программа с модулями. **Фрактал из одной единицы**,
повторённой на всех масштабах без изменения формы:

```
агент → цех → студия/биржа → квартал → город → города
```

Каждое звено — **самостоятельная единица** (житель). Полная формула
единицы (уточнена 03.07, полный разбор — `ЧЕРТЁЖ_ЕДИНИЦЫ.md`):

```
ЕДИНИЦА = РОД + МАСКА + ХАРАКТЕР + ПАМЯТЬ + ОПЫТ + СТОЛ
        + ИНИЦИАТИВА + ГРАНИЦА + СУДЬЯ
```

Старая, короткая форма (для быстрого чтения, без потери смысла):
```
ЖИТЕЛЬ = паспорт(род-якорь) + память + архив
       + работа(маска) + жильё(место) + связи + вход↔выход
```
Один шаблон, вложенный в себя. Строим по кирпичикам, по одному,
до зелёного. Кирпич должен стоять сам.

## 2. Род, Маска, Характер — три разные оси (уточнено 03.07)

**Род** — дно. Кто единица ДО всякого дела, навсегда, не судится,
не выбирается. **Маска** — кем показываюсь В ЭТОМ МОМЕНТЕ, лицо к
конкретному собеседнику/месту. **Характер** — какой я СКВОЗЬ ВСЕ
маски, ручки натуры, не меняются от одного факта.

```
КТО он     → паспорт (род-якорь). Неизменное дно.
КАКОЙ он   → характер (ручки: Empathy/Resonance/Stubbornness + свои).
КЕМ показывается → маска. Бесконечно много, меняется без акта.
ГДЕ живёт   → жильё (прописка). Уровень 3, меняется жизнью.
```

## 2.1а. Роль ≠ Маска (правка 03.07 — узел Сета)

Раньше (§2.2 старой редакции) роль и маска были слиты в одно. Узел
Сета развязал: у Сета РОЛЬ одна («бриф-менеджер»), МАСОК тринадцать
(по цеху-собеседнику). Значит это два разных этажа:

```
РОЛЬ (месяцами, акт смены)          МАСКА (сейчас, шаг через порог)
  ТИП (резидент/хранитель/воркер)     Лицо к конкретному собеседнику/
  ПОРОДА (цех-принадлежность,         месту. Бесконечно много (§2.2а).
    НЕ родина — задаётся с            Опорная пятёрка с домом в коде:
    пропиской, Уровень 2)             ДОМ/ЦЕХ/СОВЕТ/ГОСТЬ/СОБЕСЕДНИК.
  CORE_PHRASE (ядро роли)             Переключение: у Сета/Артура —
  СТАДИЯ ПУТИ (1/2/3, метрики         вызывающий код НАЗЫВАЕТ маску
    сигналят, Шеф подписывает)        параметром (mask_name=dept),
                                       не распознаётся на лету.
```

Порода **не родина** (это была ошибка первой мысли, поправлено):
откуда родом, если вообще нужно — прозой в `Hidden_History`, не
полем. Порода = какой цех, задаётся ВМЕСТЕ с пропиской, только для
яруса РАБОТЫ. Внутри маски есть ещё этаж — ГЛАВНАЯ (пятёрка, дом в
коде) и ПОДМАСКА (файл внутри, бесконечно, как `forge/masks/{цех}.md`
у Сета — 13 файлов внутри одной ГЛАВНОЙ «ЦЕХ»).

## 2.2а. Маска бесконечна, дом в коде — только у немногих

**Масок — бесконечное множество** (слово Шефа, 03.07: «кем себя
нарисую — то и маска»). Опорная пятёрка (Дом/Цех/Совет/Гость/
Собеседник) — НЕ полный список, а те немногие, кому дали постоянную
инфраструктуру (папка, фон, `mask.json`). Остальные маски единица
играет так же честно, без своей папки — как костюм на один раз не
получает гардеробной. Закон Души (XI, Свод Заповедей) не страдает:
душа одна под любой маской, посчитана она в файле или нет.

Гость — не «на публике» (слабый довод, публика бывает и без гостя),
а **в ЧУЖОМ месте**: приглашён или нет («нежданный гость», прогнать
нельзя). Собеседник — не про знакомство, а про САМ ФАКТ разговора
прямо сейчас (со-БЕСЕДА): спросил время у чужих на остановке —
уже собеседник, хоть до вечера проговорил с незнакомцами.

## 2.3. Локация = самостоятельная единица (закреплено 30.06)

**Локация — недвижимое. Единица с паспортом, как житель, но НЕ дышит:**
нет движка, 4 слоёв, маски. Плоский паспорт — один файл.
```
ЛОКАЦИЯ → passport.json (место вообще: стены, вид, атмосфера)
ЖИТЕЛЬ  → папка: passport + core/resonance/sensory/archive + маски/ (дышит)
```
Закон Движимого/Недвижимого: житель НИКОГДА не лежит внутри локации —
только ссылкой. «Где житель» = последняя запись в sensory.

**Иерархия города (4 уровня):**
```
ГРОНДХЕЙМ (город 0000 — сам холст)
   РАЙОНЫ: Деловой центр · Портовый узел · Храмовый комплекс (поле District)
   КВАРТАЛ = САМ объект-локация вида «жильё», НЕ контейнер, НЕ поле.

   ЛОКАЦИИ: Студия, Биржа, Маяк, Высотка, Гексагон...
```
Поле «Квартал» УБРАНО из формы локации. Осталось «Район». Соцпрофиль места

## 2.4. ДОМ — построен и работает (закрыто 01.07, было «зреет» 30.06)

**Прописка = ДОМ** (где спит, ест, отдыхает, СНИЖАЕТ плохой стресс).
Оформляет **Брат в своём кабинете** (`/brat`, кнопка «Прописка») —
НЕ в кабинете жителя, как проектировалось 30.06: Брат СВЯЗЫВАЕТ,
прописка — связь двух единиц, это его работа узла, не личный
диалог жителя с собой (правка 01.07).

**Дом ≠ экран. Дом — часть личности, носимая ВСЕГДА** — построено,
не только спроектировано:
```
житель ВСЕГДА несёт в себе (vydoh_stol(), любой заряд):
   КТО Я (личность)        — паспорт, якоря, история, натура
   ГДЕ МОЙ ДОМ + ЧТО ТАМ    — домашний_промпт (личный текст: чайник
                              со сколотым носиком, что угодно —
                              пишет Шеф руками, как и старый
                              home_prompt.md студии `-2`)
   ГДЕ Я СЕЙЧАС            — фон кабинета по прописке (image.*
                              локации, третий приоритет в
                              _bg_for_mask, после маски и своего bg)
```
Пусто, если не прописан — строка просто не появляется, ничего не
выдумывается (YAKORYA_V_SOUL_V1: пустые поля пропускаются).

**Дом — место ДИАЛОГА**, лечащего стресс (как cabinet_chat `-2`).
Образец `soul_tools.py`/`prompts.py` из `-2` уже сверен и перенесён
частично — паттерн MEMORY_REQUEST оттуда портирован тонкой веной
(§4а ниже), Оле как отдельный носитель памяти — НЕ перенесена,
пока не нужна (§4а).

**РАБОТА — другое, сложнее:** id + должность + пайплайны (машина
труда). Не путать с домом:
```
РАБОТА → дело: id + должность + пайплайн
ДОМ    → отдых: сон, еда, снятие стресса, ДИАЛОГ + «не забывать себя»
```

## 3. Заряд (то, что звали стрессом) — уточнено 02.07

Раздражитель ±, маятник к нулю-балансу. Полярность −1..+1. Не копится —
уравновешивается. Сила = глубина касания по воронке памяти.

**В душу подаётся словами настроения, не числом** (правка 02.07,
`patch_nastroenie_slovami.py`): «тебе тепло и светло» вместо «заряд
0.35 (от -1 до 1...)». LLM держит тон по словам лучше, чем по числу
с инструкцией расшифровки.

## 4. Воронка памяти + четыре слоя (ИСПРАВЛЕНА ошибка 30.06→02.07)

```
маяки/метки → sensory ⚡ · маски → маски/ · связи → resonance 🩸
род → core 🦴 (=паспорт) · тишина → archive 🌑
```
Гравитация ЗАПИСИ: вес = резонанс_с_родом × резонанс_с_маской ×
плотность_связей. Это КУДА оседает факт — верно, не тронуто.

**ИСПРАВЛЕНО (было прямой ошибкой в редакции 30.06 — §5 ниже):**
заряд НЕ определяет, что читается назад. «Открытые по |заряда| слои
→ в промпт» (старый замысел Части V) был спроектирован, начат и
ОТВЕРГНУТ САМИМ ШЕФОМ 02.07: «я не так хотел, я хотел оценить
настроение, а не чтобы стресс решал за жителя». Вычищено из кода
(строка «тебе открыты слои памяти» физически удалена из
`ui_zhitel.py`). Взамен — см. §4а.

## 4а. MEMORY_REQUEST — воля решает читать (построено 01.07)

Житель САМ решает вспоминать — не заряд, не порог. Перенесено
тонкой веной из `-2` (Спринт 43, `grondheim_memory.py`, паттерн
Оле: «Если что-то кажется знакомым, но не помнишь — напиши
MEMORY_REQUEST»). В душу — подсказка; если житель написал в ответе
`MEMORY_REQUEST: <что>` — движок сам ищет текстом по своим трём
слоям (`vspomnit()`), поднятое подкладывается, житель отвечает
ВТОРОЙ раз, уже помня. Шеф видит только финальный ответ. Один
подъём за ход, без петель. Ничего не нашлось — честное «следа нет»,
без выдумки. **Воля выше стресс-шлюза** — подъём безусловный,
работает даже при заряде 0 (проверено вручную).

Городская память (Оле, отдельный хранитель памяти НЕ СВОЕЙ, а
чужой на хранении) — в Грондхейме НЕ построена, решено не строить
(«пока нет, каждый держит свой архив сам», 03.07). Увядание/Family
Album (`-2`: 30 дней + вечное по весу) — тоже отложено («пусть
копится, пока не заболит», 03.07).

## 5. Тело носит лёгкое · Чувство не отчёт

Единица не таскает бездну. Тело — лёгкое (паспорт, свежесть, адреса).
Глубина — по запросу (MEMORY_REQUEST, не «у хранителя» — Оле не
построена в этом городе, §4а). ~~Заряд меняет ЧТО доступно (какой
слой открыт), не строчку~~ — ЭТА СТРОКА БЫЛА ОШИБКОЙ, см. §4,
вычеркнута 02.07. Заряд меняет НАСТРОЕНИЕ (слова, §3) и, в проекте
на будущее (не построено), глубину ЗАПИСИ нового факта («искра
выбора» — сильно тронуло → archive, слабо → sensory; см. Чертёж
Единицы, Гл.2/3) — никогда не глубину чтения назад.

## 6. Память: рамка одна, наполнение разное

TURBO — лента (RAM). TRADING — архив с историей. LIVING_BOOK —
рукопись (сестринский проект, свой Маяк-ретранслятор, свой
`biography_snapshot` — память О РЕБЁНКЕ, не о себе; см. Чертёж
Единицы, если понадобится). Образец «руки в долгую память» —
trading (remind/remember).

**Метки (растущая область, не факт — см. Чертёж Единицы, Закон
Меток)**: `тип: значение` рядом с записью, для поиска по категории,
не по тексту. Первое готовое применение — не построено ещё: спасти
тонус (`_otsenit_tonus_silu()` уже считает плюс/минус/ровно и
выбрасывает) меткой рядом с sensory-записью.
