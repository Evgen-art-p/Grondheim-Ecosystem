## 1. Что такое Биржа

Биржа — не файл и не функция, а **квартал города**, такой же
самостоятельный, как Брат/жители/ГОРОД: свой код, свои данные, свой
район на карте.

```
ГРОНДХЕЙМ (город)
  └─ Деловой центр (район)
       └─ Торговый Квартал (0013_TRADING_QUARTER, локация-жильё)
            └─ Биржа (0014_EXCHANGE, здание — тут сидит Совет)
```

Клик по зданию Биржи на визуальной карте (`/grondheim`) ведёт прямо в
кабинет Совета (`/torg`). Биржа держит Совет из девяти торговых единиц.
Торгуют **не только золотом** — любыми активами, и **не только по
методологии Вильямса/Котина** — это один метод, живущий в цехе
«Торговый Хаос». Кнопка «РЫНОК» — живой контур (терминал MT5 → бары →
ядро → цепочка живых LLM-агентов). Кнопка «ТЕСТЕР» — та же цепочка на
исторических CSV, без MT5.

## 2. Архитектура — два Закона Картриджа разом

Закон Картриджа работает и для данных (манифест цеха, слоты, промпты),
и для кода (мозг слота):

```
СЛОТ НЕСЁТ С СОБОЙ ВСЁ:
  GRONDHEIM_CITY/Биржа/цеха/{цех}/слоты/{слот}/
    ├── промпт.md        — кто эта роль и как думает
    ├── знания/          — база знаний роли (математика Вильямса и т.п.)
    ├── данные/          — личная статистика РОЛИ (не резидента!)
    └── мозг.py          — код роли
```

Кабинет/тестер/хуки не хранят списка агентов и не импортируют их по
имени — `_slot_brain(ceh_id, slot)` открывает `слоты/{slot}/мозг.py`
прямо по пути. Кто сидит в слоте — решает Закон Пары: `mask.json`
резидента в его домашней папке, кабинет резолвит через
`cartridge_registry.resolve_para(цех, слот)`.

## 4. Кабинет — `Биржа/ui_torg.py`

```
ХЕДЕР   — 9 пузырьков состава Совета
ЛЕВАЯ   — загрузчик истории CSV + полка заряженных активов
СТОЛ    — тулбар (РЫНОК, тумблер РЕАЛ/ТЕСТЕР, поле «ловить») + чат
           + окно отчёта
ПРАВАЯ  — портрет активного агента + живые показатели + приборы сенсора
```

Кнопка РЫНОК/ТЕСТЕР зовёт ОДНУ дверь — `council.wake_council()`:
Искра → (если спуск нашёл точку) Морж → Паникёр → Ганс → Архивариус →
три трейдера → Исполнитель. Тумблер РЕАЛ/ТЕСТЕР переключает живой
MT5-терминал и прогон по CSV. Тумблер 🎓 УЧИТЬ (виден в режиме ТЕСТЕР):
выкл — стерильный прогон, паспорта жителей не трогаются; вкл — якоря и
заряд растут, как в реале.

## 6. Что реально живо (проверено, не на словах)

- Кабинет открывается, прописка резолвится, все девять мозгов грузятся
  из своих слотов и отвечают через живую LLM.
- Полный цикл Совета проверен живьём: спуск → Совет → вердикт →
  Исполнитель → сделка видна лентой (открытия и закрытия).
- Компас-дисциплина подтверждена живым текстом рассуждений трейдеров.
- Нога Опыта работает на живых деньгах — заряд качается каждой сделкой,
  жители ссылаются на свой опыт вслух и отличают похожее от обманчиво
  похожего.
- Ведение позиции: стоп/доливка/закрытие событийно, обратная пирамида,
  пакетный расчёт R.
- Ошибки не молчат — сбой любого агента печатается наравне со всеми.

взять эту трубу, дав свой классификатор и своего судью.

## 10. Уроки (кратко, без историй)

- `except: pass` — самая дорогая строка: ошибка, которая молчит, дороже
  ошибки, которая падает.
- Домысливать вместо того, чтобы посмотреть в источник — самый дорогой
  навык Брата. Сначала диск, потом рассуждение.
- Проверка должна показывать факт (имя, число, живой вывод с диска), а
  не галочку «✓ готово». Пластик прячется в галочках.
- Одна сущность — несколько читателей/писателей → лечить нужно всех
  найденных `grep`-ом, не одного.
- Чутьё Шефа на «так не бывает» точнее рассуждений Брата — когда он
  говорит «не верю цифре», надо не спорить, а вскрывать.
- Не подгонять число/порог под ориентир задним числом — тот же урок
  повторялся минимум трижды (амплитудные пороги, частота сигналов,
  сегодняшний конец волны C).
