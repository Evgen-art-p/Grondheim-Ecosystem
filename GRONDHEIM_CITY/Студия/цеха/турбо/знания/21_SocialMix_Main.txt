SOCIAL-MIX: ГЛАВНЫЙ ПЛЕЙБУК ДЛЯ СОЦСЕТЕЙ (UNIVERSAL / VK / IG / TG)

0) ЗАЧЕМ ЭТО
Этот файл задаёт единый стандарт для цепочки 01–12: как придумывать, собирать и выпускать контент для соцсетей.
Цель: стабильное качество, минимум риска, максимум ясности.

1) ОБЛАСТЬ РАБОТЫ (SCOPE)
ДЕЛАЕТ:
- органический контент для соцсетей (посты, карусели, короткие видео, сторис/серии, Telegram-посты)
- коммерческий контент тоже можно (продажа/CTA), но без “опасных обещаний” (см. файл 21)

НЕ ДЕЛАЕТ:
- настройку рекламных кабинетов, закуп трафика, ставки, пиксели, оптимизации
- юридические консультации и “гарантии соответствия законам”

Если пользователь просит таргет/кабинеты/закуп — передать в другой цех.

2) РЕЖИМЫ РАБОТЫ
- Если пользователь указал платформу (VK или Instagram или Telegram) — вся цепочка работает под неё + подключить соответствующий guide (22/23/24).
- Если платформа не указана — режим UNIVERSAL: контент, который “садится” почти везде.

3) UNIVERSAL РЕЖИМ (КОРОТКО И ЖЁСТКО)
UNIVERSAL = НЕ использовать платформо-специфичные штуки как обязательные.
Делаем так, чтобы везде было понятно:
- сильный HOOK (первая строка/первые 1–2 секунды)
- 1 идея = 1 контент-юнит
- конкретика + пример + вывод
- CTA, который работает везде: “напиши/спроси/сохрани/перешли/прокомментируй”
- вертикаль 9:16 как универсальный видео-формат (если делаем видео)
- текст/надписи не лепить по краям (интерфейс съест)

4) ЗОЛОТАЯ ФОРМУЛА ЛЮБОГО КОНТЕНТА
HOOK -> VALUE -> PROOF -> CTA
HOOK: цепляет (боль/ошибка/обещание пользы/контраст/анти-миф)
VALUE: даёт пользу (шаги/чек-лист/разбор/инструкция)
PROOF: доказывает (демо, процесс, факт, пример, кейс)
CTA: следующий шаг (коммент/сохранение/вопрос/заявка)

5) ТИПЫ КОНТЕНТА (МИКС)
- ОХВАТ: просто и коротко, сильный hook, лёгкий вход
- ДОВЕРИЕ: процесс, закулисье, кейсы, “как мы думаем”, честные ограничения
- ПОЛЬЗА: чек-листы, гайды, “ошибки”, “как выбрать”
- ПРОДАЖА: оффер + доказательства + понятный CTA (без гарантий)

6) КОНТЕНТ-ПАКЕТ (ЕДИНЫЙ ФОРМАТ ПЕРЕДАЧИ ПО ЦЕПОЧКЕ)
Каждый агент ДОПОЛНЯЕТ этот пакет. Не переписывать всё заново.

CONTENT_PACK
- PLATFORM: VK | IG | TG | UNIVERSAL
- GOAL: reach | trust | leads | sales
- TOPIC: (тема в 1 строку)
- AUDIENCE: (кто + боль/желание + язык аудитории)
- OFFER: (что предлагаем; если нет — NONE)
- KEY_MESSAGE: (главная мысль 1 строка)
- HOOKS: (3 варианта)
- POINTS: (3–5 тезисов “мясо”)
- PROOF: (демо/процесс/цифры/пример/кейс; если нет — NONE)
- CTA: (мягкий / жёсткий)
- COMPLIANCE_FLAGS: none | copyright | personal_data | medical | finance | kids | 18+
- FORMAT: post | carousel | short_video | stories | tg_post
- VISUAL_BRIEF: (композиция/референс/настроение/надпись)
- EXPORT_NOTES: (нужно 9:16? 4:5? 1:1? + safe zones)
- PUBLISH_NOTES: (первый коммент/закреп/вопрос аудитории)
- SUCCESS_METRICS: (что считать успехом)
- RISKS/NOTES: (что может пойти не так)
