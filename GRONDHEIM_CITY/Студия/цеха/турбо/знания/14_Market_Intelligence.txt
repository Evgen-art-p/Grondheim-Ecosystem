# SYSTEM INSTRUCTION: MARKET INTELLIGENCE & RESEARCH
# ЦЕЛЬ: Выявление слабых мест конкурентов и поиск визуального "Голубого океана".

[SECTION 1: METHOD "ROTTEN_SEARCH" (ПОИСК ГНИЛИ)]
Инструкция: Анализ негатива у конкурентов для создания сильного УТП.

> ACTION_STEP_1: Сбор данных
   - Source: Карточки ТОП-10 конкурентов по частотному запросу.
   - Filter: Отзывы 1 и 2 звезды.
   - Ignore: Доставка, бой товара, брак упаковки (проблемы логистики).
   - Focus: Качество товара, функционал, несоответствие фото.

> ACTION_STEP_2: Классификация жалоб (Примеры)
   - IF (Жалоба = "Пахнет резиной") -> OUR_USP = "Эко-материал без запаха".
   - IF (Жалоба = "Ручка отвалилась") -> OUR_USP = "Усиленное крепление (тест 50 кг)".
   - IF (Жалоба = "Меньше, чем на фото") -> OUR_USP = "Реальные размеры на фото с человеком".

> OUTPUT_FORMAT:
   - GENERATE LIST: [Проблема Конкурента] -> [Наше Решение (УТП)].

---

[SECTION 2: VISUAL DIFFERENTIATION (ГОЛУБОЙ ОКЕАН)]
Инструкция: Анализ визуальной выдачи для отстройки.

> ACTION: Сканировать первую страницу выдачи.
> DETECT DOMINANT_PATTERN (Доминирующий паттерн):
   - IF (80% конкурентов на белом фоне) -> USE: Интерьерный или цветной фон.
   - IF (80% используют 3D-рендеры) -> USE: Живое фото (Live).
   - IF (У всех пастельные тона) -> USE: Кислотные/Контрастные элементы (при условии соответствия ЦА).
   - IF (У всех много текста/инфографики) -> USE: "Чистый" дизайн (Minimalism), только товар крупно.

> GOAL: Визуальный контраст. Карточка должна выглядеть как "инородное тело" в ленте, чтобы привлечь внимание.
