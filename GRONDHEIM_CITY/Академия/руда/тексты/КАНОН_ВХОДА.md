## 1. Фундамент — на чём стоит всё

**① Рынок нелинеен, потому что это психология.** Реакция продавцов и
покупателей — не механика, а психология толпы: непостоянная, зависящая от
контекста. **В этом и есть затык всех существующих методов** — они считают
линейную математику (фиксированные формулы, одинаково реагирующие всегда).
Вильямс — нет. Его метод пытается прочитать саму нелинейность, а не
сгладить её линейной формулой. Отсюда и следствие для архитектуры:
**индикаторы не могут командовать** — только формула может «командовать»
однозначно, а нелинейную психологию однозначно не описать.

**② Цена дышит всегда. Импульс-коррекция-импульс-коррекция, без остановки,
в обе стороны по масштабу.** Даже когда на этом ТФ виден флэт — глубже по
ТФ рынок дышит; иначе рынка вообще нет (нет спроса-предложения,
купи-продай). Полная цепь без начала и без дна:

```
… импульс → зигзаг(коррекция) → Искра ловит конец C → новый импульс →
его коррекция (новый зигзаг) → новая Искра → …
```

Работает **зеркально** (вниз — та же логика, знак отражён) и
**фрактально внутрь** (тот же узор импульс/коррекция повторяется на любом
масштабе вложенно — своя Искра на своём этаже). Величина/старшинство
зигзага **не принципиальна** — какой нашли изначально на снимке, тот и
работаем, не гонимся за «главным».

**Фрактальность даёт один принцип для волны любой** — не отдельное
правило для C, отдельное для волны 2, отдельное для волны 5. Один и тот
же закон, просто на разных этажах и в разных ролях (импульсная волна
или коррективная). **Весь рынок — это комбинация волн**: ничего другого
там нет, только они, вложенные друг в друга на всех масштабах.

**③ Все индикаторы — производные от цены, а цена сама — след толпы.**
Аллигатор показывает **момент согласия участников** — где бы цена была,
если бы толпа сейчас согласилась в направлении. Переплетение линий — нет
согласия. Раскрытая пасть — согласие есть. AO, MFI, дивергенция — не
абстрактная математика, а зашифрованная реакция живых людей. Цена — их
первый след, индикаторы — производные на два шага дальше.

**④ Индикаторы — ориентиры, НЕ сигналы.** Ни один индюк не командует
«вход». Все — факты на столе (Profitunity Trading Partner, TRADING_CHAOS
§4: лист заполняется фактами, решение — последняя строка, трейдера).
Компас, пасть, AO, ангуляция, дивергенция — ориентиры. Путь по их
комбинации ищет **трейдер.**

**⑤ Свойство ≠ определение.** Фрактал — свойство: «как правило» образуется
на развороте, но может быть, а может не быть. На него НЕ опираемся при
определении разворотника. Дивергенция — тоже ориентир, не жёсткое условие.
**Разворотный бар — единственное, что определено строго**: одна свеча,
читается на себе (см. §2.4).

**⑥ Математику считает код. Решает — только LLM, и только на готовом.**
Чтобы LLM не глючил (не придумывал числа вместо расчёта): AO, Аллигатор,
пики, дивергенция, ангуляция — всё считается детерминированным кодом
заранее и подаётся агенту готовым. LLM никогда не вычисляет сырые бары
сам — он читает посчитанное и **интерпретирует**, взвешивает, решает. Это
и есть роль трейдера по Вильямсу, перенесённая на агента.

## 2. Что ловим — конец волны C

### 2.1. Модуль 6.2 — для зигзага-C, всегда

Волна C (последняя нога зигзага-коррекции) **всегда выстреливает из
пасти с ангуляцией.** Условия дословно (Единая_торговая_система §6.2):

> 1. Визуально завершена пятиволновка.
> 2. Дивергенция на осцилляторе AO.
> 3. Цена «оторвалась» от Аллигатора (угол острее угла линий).
> 4. Появление Разворотного Бара: обновляет локальный экстремум,
>    закрывается в противоположной половине.

РБ — **всегда пункт 4, последний.** Первые три очерчивают, что мы у
конца волны; РБ — печать в этой зоне, не поиск по всему графику.

**Важная оговорка:** ангуляция не всегда чётко видна именно на этом
этаже/C. Но **если она есть — это сильнейший маяк из всех.** Не видно
чётко на текущем ТФ — правильный ход: **спуститься на ТФ ниже и
посмотреть там.** Хороший практический маяк для пункта 3 — пара точек:
самый экстремум цены **и** соответствующая точка на линии Аллигатора в
тот же момент; расстояние между ними и есть измеримая ангуляция.

### 2.2. Анатомия зигзага A-B-C

**Волна C — откатная, контр-трендовая. Всегда против тренда**, не часть
его и не начало нового движения — просто чтобы больше не путать: тренд
вверх → C идёт вниз (против); тренд вниз → C идёт вверх (против). Это и
объясняет, почему C не может выстрелить прямо из вершины импульса —
сначала A, потом B (к пасти), и только затем C выстреливает из пасти.

Тренд вверх (глобальный, старшая пасть). Откат вниз — зигзаг A→B→C:

- **A** — первый сброс от вершины предыдущего импульса.
- **B** — откат, возвращает цену **К пасти** (баланс). Конец B = цена у
  пасти.
- **C** — **выстреливает ИЗ пасти прочь.** Отрывается от линий — это и
  есть ангуляция, растущая величина («чем ярче отрыв — тем сильнее конец»,
  не флаг «есть/нет»).

Пасть — точка равновесия: импульс выстреливает ИЗ неё, откат возвращает
К ней, следующий выстрел — снова ИЗ неё.

### 2.3. Дивергенция — внутри C, не на C целиком

C сама — пятиволновка (Эллиотт: зигзаг 5-3-5, C — последняя пятёрка).
**Дивергенцию не увидеть на C как таковой — только на развороте
ВНУТРЕННЕЙ 5-й волны C**, её последнего рывка. TRADING_CHAOS §3.4:

> Конец волны 5: дивергенция между ценой (новый максимум) и гистограммой
> (ниже, чем на волне 3).

Механика: код **держит в памяти пик гистограммы на внутренней 3**, чтобы
сравнить с пиком на внутренней 5 (цена дальше, гистограмма слабее).
Расхождение — дивергенция.

**Фрактальный бонус:** конец внутренней 5-й волны C = конец всей C. Одна
точка на двух масштабах — не нужно искать их раздельно.

### 2.4. Разворотный бар — самодостаточная свеча

**Разворотник — не фрактал.** Фрактал — свойство, «как правило»
образуется на развороте, но может быть, а может не быть — на него не
опираемся. Разворотник определяется **на себе, одним баром**, без
соседей:

- Конец C при тренде ВВЕРХ: `low[i]` — новый минимум (хвост вниз),
  `close[i] > (high[i]+low[i])/2` (закрытие в верхней половине).
- Зеркально при тренде ВНИЗ.

### 2.5. Два разворотника подряд — эстафета по исходу первого, не связка

Если РБ на конце C не один, а подряд два (часто бывает) — не связка «взять
оба разом», не отмена первого вторым. Правило простое:

1. Появился первый РБ → выставляем на нём ордер сразу.
2. Пока по первому позиция открыта / заявка ещё не тронута стопом
   («болтаемся в рынке») — **второй РБ игнорируется**, ведём то, что уже
   начали.
3. Если первый уже **вынесло стопом** — второй РБ становится **новым,
   свежим входом.**

**Важно про роли:** это не решение станции (Искры) — это решение
**трейдера.** Искра/станция только **показывает** оба разворотника, когда
они появляются. Есть ли уже открытая позиция от первого, что с ней делать —
не забота станции; трейдер видит показанное и решает сам.

**Отдельный нюанс — два РБ в одном снимке могут быть от РАЗНЫХ трейдеров,
не повтором одного и того же сигнала.** Эстафета выше (п.1-3) — про один
и тот же тип сигнала, повторившийся дважды подряд. Но бывает и так: первый
РБ — конец C, сигнал Авантюриста (зашёл он или пропустил). Дальше пошла
волна 1, фрактал, волна 2 — и на конце волны 2 появляется **свой,
отдельный** РБ — сигнал Васи (см. §4). Если Авантюрист уже в рынке от
первого РБ — Васин сигнал **всё равно работает**, это его собственная
задача, не то же самое событие. Оба легитимны одновременно, не
конкурируют и не отменяют друг друга — просто разные роли смотрят на
разные РБ.

## 3. Сквозная цепь — обе стороны

**Тренд ВВЕРХ (старшая пасть вверх, компас):**
тренд вверх → выстрел C вниз из рабочей пасти (ангуляция) → внутри пики
3/5 своей 5-волны → дивер (5 против запомненного пика 3) → разворотник
на конце внутренней-5=конце C (новый минимум, закрытие вверху) → стол
ориентиров (АО, ангуляция, пасть, фаза толпы) → трейдер читает
комбинацию → **вход ВВЕРХ, по тренду.**

**Тренд ВНИЗ — зеркально**, знак отражён, логика одна.

Сторону тренда задаёт **старшая пасть** — она же и мера направления
предыдущего импульса: одно и то же измерение, не два разных.

## 4. Что происходит ПОСЛЕ Искры — вся цепочка входов

Это самое важное уточнение сессии: Искра — не одна из равных станций.
**Она открывает движение.** До неё — просто зигзаг (коррекция). После
неё — начинается новый импульс, и уже внутри него у каждого трейдера
своя точка, свой ключ.

### 4.1. Порядок появления структуры (не порядок исполнения!)

```
Искра ловит конец C (разворотник)
  → открывается волна 1 нового импульса
    → на макушке волны 1 — фрактал
      → коррекция от волны 1 = волна 2
        → Вася (Консерватор) ловит конец волны 2 (свой РБ)
          → волна 3 пробивает макушку волны 1 (пробой фрактала)
            → Ганс/Брут берёт пробой
```

**Про фрактал — важное уточнение.** Фрактал **есть всегда**, закон
постоянен и закономерен, никакой эстафеты и сдвигов нет. Переменная —
только **видимость**, зависит от ТФ и масштаба наблюдателя:
- если волна 1 слишком мелкая на рабочем ТФ — фрактал на ней просто не
  разглядеть (закон не изменился, просто окно наблюдения не поймало);
- если волна 5 **усечена** (Эллиотт §2.1: «волна 5 не может преодолеть
  экстремум волны 3») — самый дальний экстремум движения и так стоит на
  волне 3, а не 5. Это не «фрактал сместился» — это то же самое
  постоянное правило (экстремум там, где он есть по факту цены), просто
  в этом случае показывающее себя на другом номере волны.
Тонкости здесь есть, и это скорее практическое знание трейдера, чем
явная строчка в загруженных первоисточниках — при дальнейшей стройке
сверяться с Вильямсом внимательнее именно по этому узлу.

Волна 2 сама — тоже маленький зигзаг (фрактальность), и Вася её конец
ловит той же механикой РБ, только этажом мельче и без требования яркой
ангуляции (движение молодое, пасть ещё не разошлась широко).

### 4.2. Порядок ФАКТИЧЕСКОГО срабатывания ордеров — по времени

**Авантюрист (Илья) → Вася (Консерватор) → Ганс/Брут (пробой фрактала).**

Путаница в старом коде была именно здесь: **фрактал на графике рисуется
раньше** (сразу на макушке волны 1), но **срабатывает как сигнал
(пробой волной 3) позже**, чем успевает отработать Вася на конце волны 2.
Нельзя путать «когда точка появилась на графике» с «когда она сработала
как сигнал для входа» — это и развело порядок неправильно.

### 4.3. Профиль риск/объём каждого трейдера

| | Когда входит | Риск | Почему |
|---|---|---|---|
| **Авантюрист (Илья)** | раньше всех, на самой волне 1 | больше всех | не знает заранее, какой волной по большому счёту окажется этот импульс (может статься, что это волна 4, а не 3) — риск в неопределённости номера, не только в стопе |
| **Вася (Консерватор)** | конец волны 2 | меньше, короткий стоп | входит ПОСЛЕ того, как 1 и 2 внутри импульса уже сложились — значит следующее гарантированно 3-я волна ЭТОЙ локальной структуры, независимо от номера в большом счёте. Лучшее соотношение риск/потенциал (вся 3-я впереди) |
| **Ганс/Брут** | пробой макушки 1 волной 3 | минимальный, подтверждено | но и меньше всех объёма — часть 3-й уже прошла до пробоя |

### 4.4. Как каждый просыпается — по ключу, не бар за баром

Не полинг «на каждом баре проверяем всех». **У каждого свой факт-ключ**,
событие, на которое просыпается именно он:
- Авантюрист — свой разворотник (конец C).
- Вася — свой разворотник (конец волны 2).
- Ганс/Брут — пробой фрактала.

**Но Искра — не в очереди наравне с ними.** Она — корень: без её
пробуждения (конец C) вообще не существует ни волны 1, ни волны 2, ни
фрактала — структуры, на которой могли бы сработать чужие ключи. Она
первая просто потому, что с неё всё начинается.

## 5. Действие — здесь и сейчас, не гарантия результата

**Рынок непредсказуем в принципе** (TRADING_CHAOS §1.1). Мы не гадаем,
что будет после входа — важны **условия здесь и сейчас**, не итог.

**Разворотник — с условиями, не в одиночку.** Действуем не на голую
свечу — стол вокруг неё уже накрыт (AO, ангуляция, пасть, фаза толпы —
Паникёр). Увидели разворотник в контексте стола → **действие сразу**,
не «сначала докажем условия идеально, потом решимся» как два разнесённых
шага.

**Оба исхода после входа — норма, не оценка правильности захода.** Рынок
пошёл в нашу сторону — хорошо. Не пошёл, стоп сработал — тоже хорошо: это
не сбой анализа, это нормальная часть работы. Правильность входа
определяется тем, было ли соблюдено условие момента, а не тем, что
случилось потом.

## 6. Что НЕ входит и почему (чтобы не изобрести заново)

- **Модуль 6.3 для конца ЗИГЗАГА-C** («вход на откате, РБ внутри пасти,
  отбой опоры») — выброшен для этой роли. Другого зигзага-C, кроме
  выстрела с ангуляцией (6.2), не бывает.
- **Ноги зигзага / автомат A-B-C с пробоем экстремума A** (черновик
  БИРЖА.md §5с п.4, фракталы Ганса как скелет) — убран целиком. Разворотник
  определяется на себе (§2.4), не разметкой ног через фрактал.
- **Фрактал как определение разворотника** — фрактал свойство (может
  быть/не быть), не признак. Разворотник самодостаточен.
- **Дивергенция AO как обязательное И-условие разворотника** — отвергнуто.
  Дивер — ориентир на столе (§1④/⑤), не замок, определяющий саму свечу.
- **«Резинка» как философский механизм «C возвращается в пасть»** —
  отвергнуто как ошибочная формулировка (C не возвращается, а
  выстреливает ИЗ пасти). Числовая метрика с похожим именем встречается в
  репозитории («резинка Джастин» — дистанция цена↔Lips) — см. §9, но это
  отдельный от нашей философской «резинки» вопрос, не путать.
- **Жёсткие ворота-фильтр («И»-связка всех условий отсекает вход)** —
  отвергнуто. §5о БИРЖА.md: ворота выкашивали 87% честных точек. Индикаторы
  кладут факты, трейдер решает.
- **Порядок исполнения = порядок появления на графике** — отвергнуто (§4.2).
  Фрактал рисуется раньше волны 2, но срабатывает позже Васиного входа.

## 7. Открытые узлы — для следующей сессии

1. **Число ангуляции.** §2.1 даёт маяк (пара точек: экстремум цены + точка
   на линии Аллигатора, расстояние между ними), но точная формула (окно,
   нормировка) не согласована как канон — только нащупана.
2. **Окно памяти пика 3 внутри C** (§2.3) — за сколько баров код держит
   «пик внутренней 3», чтобы сравнить с внутренней 5. Не задано.
3. **Как трейдер-агент читает комбинацию.** §1④/§5: не И-связка, а
   суждение по столу ориентиров. Механизм такого суждения (LLM-рассуждение
   vs взвешенная оценка) не спроектирован.
4. **Связь с открытым долгом БИРЖА.md §5с** — «эстафета станций во
   времени» (точка перерождается быстрее, чем доживает до сигнала). Этот
   канон должен лечь так, чтобы конец C доживал до разворотника, а Вася —
   до конца волны 2, без потери состояния между барами.
5. **Формулы Паникёра, MFI/Squat** — почти не тронуты в этой сессии,
   ждут отдельного разбора (Squat — маркер конца тренда и пятая доливка
   пирамиды, НЕ первый вход — см. §9, но это из репозитория, не подтверждено
   этим разговором напрямую).

## 9. Приложение — находки в репозитории (СПРАВОЧНО, НЕ ЭТАЛОН)

Репозиторий: `https://github.com/Evgen-art-p/Grondheim-Ecosystem` (путь
и способ доступа — в шапке БИРЖА.md). Внутри уже есть формализованный слой
знаний по каждому агенту (`GRONDHEIM_CITY/Биржа/цеха/торговый_хаос/слоты/
{A01..A08}/знания/*.md`), с точными формулами из исходников MT5-индикаторов
(`iAO.mq4`, `iAlligator.mq4`, `iFractal.mq4`). **Шеф прямо сказал: то, что
обсудили в этом разговоре, — истина; репозиторий — местами запутан.**
Ниже — что там встретилось, для справки, БЕЗ статуса подтверждённого канона:

- **BuDB** (`lower_low + upper_close`) — механически похоже на наш
  разворотник §2.4, но требует отдельной проверки на совпадение полностью.
- **Дивергенция** в коде — сравнение двух **последовательных пивотов AO**
  (без привязки к номерам волн 3/5), а не «пик 3 против пика 5» буквально.
  Возможно, это то же самое другими словами — не подтверждено Шефом.
- **«Резинка Джастин»** — метрика дистанции (не угла) между ценой и
  линией Lips, с полями `distance_now/distance_max/tension_ratio/is_peak`.
  Похоже на числовой ответ для узла §7.1, но название совпадает со
  «резинкой», которую Шеф велел забыть как философский механизм (§6) —
  **не путать одно с другим**, требует отдельной сверки.
- **Три трейдера ловят структурно разные узлы** (не один и тот же конец
  C трижды): Авантюрист — конец зигзага-C (6.2-подобно); Консерватор —
  конец волны 2 (6.3-подобно, опора у пасти, без ангуляции); Брут — пробой
  фрактала. Это **согласуется** с §4 этого документа (Вася действительно
  ловит волну 2 отдельным механизмом от Авантюриста) — единственное место,
  где находка в репо совпала с прямым разбором, а не противоречила ему.
- **Искра/Морж как вето-цепь**, не равноправный стол: Искра объявляет
  DETECTED по энергии (AO), Морж может наложить veto структурой
  (ангуляция/сон Аллигатора). Похоже на разделение труда §4.4, но
  сформулировано в коде жёстче («вето»), чем в этом разговоре («стол
  ориентиров») — сверить при следующей стройке, не принимать как есть.

**Правило работы с этим приложением:** при стройке — сверять репозиторий
С этим документом, никогда не наоборот. Расхождение чинит репозиторий,
не канон.
