# Просев: MAP.md

Шеф, вот просев MAP.md. Файл не менялся — держу выводы в силе, но с оптикой последних шагов (Академия, экосистема).

**1. ЗЕРНО**
- **Маршрутизация `keywords.js`** — классификатор: слово → фильтр → узел. Без LLM, без мнения — таблица. Это готовая анатомия для починки вырожденного ключа Академии (§7.1).
- **Стейте-машина пути** — вход-фильтр-выход с возвратом «ищи». Человек решает сам.
- **`memory.js`** — два слоя (localStorage/sessionStorage) разделены честно, есть счётчики визитов, лог хранителей. Факты пишутся.
- **Пять Хранителей** — живые маски с именами и таблицей ключевых слов, каждая боль находит свой узел.

**2. ПЛАСТИК**
- **Маркер «Ты не один»** — мнение без числа: нет счётчика завершённых/незавершённых, нет метрики влияния на человека.
- **Повторный вход Безликого** («Ты уже был здесь») — порог не определён: после одного визита? После трёх? Пока декорация.
- **Память Храма** — механизм есть, а печати нет (`loss_if_forgotten`). Стык с городом не замкнут. Это не враньё — честная незавершёнка.

**3. СВЯЗИ**
- **Хранители = фрактал резидентов Грондхейма.** Те же имена (Кей, Юст, Лия, Виктор, Финч), те же спектры. Храм — внешний нерв города наружу.
- **`keywords.js` = готовая анатомия ключа паттерна** для Академии: различает оттенки смысла без счётчика.
- **`memory.js` ↔ `memory_tools.py`** — готовый шлюз: один вызов `remember()` с печатью, и боль человека станет памятью города. Пока обрыв.
- **Закон Входа-Выхода** соблюдён: слово входит → узел выходит. Но выход в город не соединён.

**4. ВЫВОД**
Забирать принцип `keywords.js` для починки ключа Академии; добавить в `memory.js` вызов `remember()` с печатью — и Храм из изолированной капсулы станет живым щупальцем Города.
