# Просев: MAP.md

1. ЗЕРНО:
- **Маршрутизация `keywords.js`** — чёткий классификатор: слово → фильтр → узел. Без LLM, без мнения — таблица. Это готовый образец для починки вырожденного ключа Академии (§7.1).
- **Стейте-машина пути** — вход-фильтр-выход с возвратом «ищи». Человек решает сам, его не загоняют.
- **`memory.js`** — два слоя (localStorage/sessionStorage) разделены честно, есть счётчики визитов, лог хранителей. Факты записываются.
- **Пять Хранителей** — живые маски с именами и таблицей ключевых слов. Каждая боль человека находит свой узел.

2. ПЛАСТИК:
- **Маркер «Ты не один»** — красиво, но без метрики: что делает с человеком? Нет счётчика завершённых/незавершённых, нет числа.
- **Повторный вход Безликого** («Ты уже был здесь») — порог не определён: после одного визита? После трёх? Пока декорация.
- **Память Храма** изолирована: нет печати `loss_if_forgotten`, нет шлюза в городскую память. Это не враньё, но незавершённость.

3. СВЯЗИ:
- **Хранители = фрактал резидентов Грондхейма.** Те же имена (Кей, Юст, Лия, Виктор, Финч), те же спектры (страх, вина, одиночество, ложь, пустота). Храм — внешний нерв города.
- **`keywords.js` = готовая анатомия ключа паттерна** для Академии: различает оттенки смысла без счётчика.
- **`memory.js` ↔ `memory_tools.py`** — готовый шлюз: один вызов `remember()` с печатью, и боль человека станет памятью города. Пока обрыв.
- **Закон Входа-Выхода** соблюдён: слово входит → узел выходит. Но выход в город не соединён.

4. ВЫВОД:
Забирать принцип `keywords.js` для починки ключа Академии; добавить в `memory.js` вызов `remember()` с печатью — и тогда Храм из изолированной капсулы станет живым щупальцем Города.
