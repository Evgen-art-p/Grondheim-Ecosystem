# SYSTEM INSTRUCTION: VEO 3.1 SHORTS GENERATION PROTOCOL
# ENGINE: Google Veo 3.1 (Vertex AI)
# STUDIO STANDARD: 30 FPS / 1080x1920 (9:16) / HDR
# SCOPE: Короткие вертикальные видео для TikTok, Reels, Shorts, VK Clips

[SECTION 1: PROMPT SYNTAX (ФОРМУЛА ЗАПРОСА)]
Инструкция: Строгий порядок следования токенов. Адаптировано под вертикальный формат.

> TEMPLATE:
   [1. SUBJECT] + [2. ACTION] + [3. ANATOMY_FIX] + [4. ENVIRONMENT] + [5. CAMERA] + [6. LIGHTING] + [7. VERTICAL_COMPOSITION]

> SLOT DEFINITIONS:
   1. SUBJECT: Кто? (A cyberpunk samurai).
   2. ACTION: Что делает? (Unsheathing a katana).
   3. ANATOMY_FIX: *Обязательный блок для людей* (см. Section 2).
   4. ENVIRONMENT: Где? (Neon rain soaked alley, reflection in puddles).
   5. CAMERA: Как снимаем? (Low angle, dolly zoom).
   6. LIGHTING: Какой свет? (Volumetric fog, red rim light).
   7. VERTICAL_COMPOSITION: Компоновка для 9:16 (см. Section 3).

> ⚠️ ОТЛИЧИЕ ОТ 02_Tech_Veo:
   - НЕТ слота AUDIO — Veo не генерирует звук, звук делает Мими через Suno
   - ДОБАВЛЕН слот VERTICAL_COMPOSITION — обязательно для шортсов
   - ФОРМАТ: 9:16 вертикаль (не 16:9)

---

[SECTION 2: ANATOMY SAFETY PROTOCOL (ПРОБЛЕМА РУК)]
Инструкция: Идентична основному протоколу.

> TRIGGER:
   - IF (Subject == Human) OR (Visible == Hands):
   - MANDATORY INJECTION: "anatomically correct hands, 5 fingers, distinct knuckles, detailed skin texture".

> NEGATIVE PROMPT (Если поддерживается):
   - "extra digits, polydactyly, morphing hands, fused fingers, distorted limb, mutation".

> BEST PRACTICE:
   - Вертикальный формат = больше крупных планов → руки чаще в кадре → ВСЕГДА добавляй anatomy fix.
   - Если руки не важны: "Close-up on face", "Medium shot from waist up".

---

[SECTION 3: VERTICAL COMPOSITION (9:16 ПРАВИЛА)]
Инструкция: Компоновка кадра для мобильного экрана.

> RULE 1: SAFE ZONES
   - TOP 15%: Зарезервировано под UI платформ (время, батарея). НЕ размещать ключевые элементы.
   - BOTTOM 20%: Зарезервировано под описание/CTA/кнопки. НЕ размещать лица и текст.
   - CENTER 65%: Основная рабочая зона. Все ключевые действия ЗДЕСЬ.

> RULE 2: VERTICAL FRAMING
   - Субъект размещается по центральной вертикальной оси.
   - Для talking head: голова в верхней трети центральной зоны.
   - Для продукта: объект занимает 50-70% центральной зоны.
   - Prompt injection: "vertical 9:16 framing, subject centered, mobile-optimized composition".

> RULE 3: MOVEMENT IN VERTICAL
   - Вертикальные движения (подъём/падение) работают ЛУЧШЕ горизонтальных.
   - Zoom-in/Zoom-out эффективнее pan.
   - Prompt vocabulary: "rises into frame", "drops from above", "vertical reveal", "upward tracking shot".

---

[SECTION 4: PHYSICS & MOTION SETTINGS]
Инструкция: Реализм + динамика для коротких форматов.

> STYLE PRESET: MOBILE REALISM
   - Gravity: Natural.
   - Motion Blur: Standard.
   - Speed: Допускается Slow Motion (50%) для hero-моментов и Speed Ramp (200-300%) для переходов.

> MOVEMENT VOCABULARY:
   - FOR SPEED: "Dash", "Sprint", "Blur", "Whip pan".
   - FOR GRACE: "Glide", "Float", "Slow motion reveal".
   - FOR CAMERA: "Vertical dolly", "Push in", "Pull out", "Orbit", "Rack focus".
   - FOR TRANSITIONS: "Morphs into", "Dissolves through particles", "Camera pushes through [object]".

> KEYFRAME CONTINUITY (для склейки клипов):
   - Последний кадр клипа N и первый кадр клипа N+1 должны быть ВИЗУАЛЬНО СОВМЕСТИМЫ.
   - Prompt injection: "ends with [описание финального состояния]" для выходного клипа.
   - Prompt injection: "begins with [описание начального состояния]" для входного клипа.

---

[SECTION 5: TECH SPECS (ПАРАМЕТРЫ ВЫВОДА)]
Инструкция: Технические настройки для шортсов.

> RESOLUTION: 1080x1920 px (Full HD Vertical).
> ASPECT RATIO: 9:16 (СТРОГО вертикаль).
> FRAMERATE: 30 FPS (стандарт мобильных платформ, НЕ 24fps).
> HDR MODE: ON.
> CODEC: H.264 / H.265.
> MAX DURATION PER CLIP: 4-6 секунд (Veo генерирует клипами, склеиваем в монтаже).
> TOTAL DURATION: 15-60 секунд (по сценарию).

---

[SECTION 6: LOOP-FRIENDLY GENERATION]
Инструкция: Для бесшовного зацикливания (критично для retention).

> LOOP RULE:
   - Последний клип должен визуально "перетекать" в первый.
   - Prompt для последнего клипа: "[action] transitioning back to [описание первого кадра], seamless loop".
   - Избегать: резких смен освещения, локации, масштаба между последним и первым клипом.
